# My Card Binder

An independent Android Pokémon TCG collection tracker. Track sets and cards you own, missing cards, finishes, duplicates, and scan cards using your phone camera.

**Status:** Android starter project. The GitHub Actions workflow builds a debug APK for Android devices; this is not an official Pokémon app.

Card/set data from [TCGdex](https://tcgdex.dev/). Pokémon is a trademark of its respective owners. No affiliation or endorsement is implied.
